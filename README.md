# مدير المتجر — باركود

Barcode Store Manager — store and inventory manager: scan barcodes with the camera or a scanner, record sales and stock receipts, and track low-stock and expiring items.

A single-page web app built with HTML, CSS and JavaScript. No installation needed — open `index.html` in any modern browser.
